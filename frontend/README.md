# БАБКИН ВНУК Mini App

Telegram Mini App для интернет-магазина.

## 🚀 Деплой

### Вариант 1: Vercel (Рекомендуется)

1. Создайте аккаунт на [vercel.com](https://vercel.com)
2. Подключите GitHub репозиторий
3. Vercel автоматически деплоит приложение

### Вариант 2: Netlify

1. Создайте аккаунт на [netlify.com](https://netlify.com)
2. Перетащите папку `dist` в Netlify
3. Получите URL для Mini App

### Вариант 3: GitHub Pages

1. Загрузите код в GitHub репозиторий
2. Включите GitHub Pages в настройках
3. Выберите ветку `gh-pages`

## 🔧 Локальная разработка

```bash
npm install
npm run dev
```

## 📱 Настройка Mini App

1. Откройте @BotFather в Telegram
2. Отправьте `/myapps`
3. Выберите вашего бота
4. Нажмите "Edit" для Mini App
5. В поле "App URL" вставьте URL деплоя
6. Сохраните изменения
