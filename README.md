# БАБКИН ВНУК - Telegram Mini-App Store

Полнофункциональная mini-app для Telegram, представляющая собой интернет-магазин цифровых товаров (игры, ключи активации, цифровые подписки).

## 🎯 Основные возможности

- **Аутентификация через Telegram**: Автоматическая регистрация и вход
- **Каталог товаров**: Игры, подписки PS Plus, EA Play, игровой донат
- **Корзина покупок**: Добавление, удаление, изменение количества товаров
- **Оплата**: Интеграция с Telegram Payments
- **Личный кабинет**: История заказов, избранное, поддержка
- **Адаптивный дизайн**: Мобильный-first подход

## 🚀 Быстрый старт

### Предварительные требования

- Node.js 18+
- PostgreSQL (или SQLite для разработки)
- Telegram Bot Token

### Установка

1. **Клонирование репозитория**
   ```bash
   git clone <repository-url>
   cd BV_mini_app_TG
   ```

2. **Установка зависимостей**
   ```bash
   # Frontend
   cd frontend
   npm install
   
   # Backend
   cd ../backend
   npm install
   ```

3. **Настройка переменных окружения**
   ```bash
   # Backend (.env)
   DATABASE_URL=postgresql://user:password@localhost:5432/babkin_vnuk
   TELEGRAM_BOT_TOKEN=your_bot_token
   JWT_SECRET=your_jwt_secret
   NODE_ENV=development
   
   # Frontend (.env)
   VITE_API_URL=http://localhost:3001
   VITE_TELEGRAM_BOT_USERNAME=your_bot_username
   ```

4. **Настройка базы данных**
   ```bash
   cd backend
   npm run migrate
   npm run seed
   ```

5. **Запуск приложения**
   ```bash
   # Backend (порт 3001)
   cd backend
   npm run dev
   
   # Frontend (порт 3000)
   cd frontend
   npm run dev
   ```

## 🛠 Технический стек

### Frontend
- **React 18** с TypeScript
- **Vite** для сборки
- **Tailwind CSS** для стилизации
- **React Router** для навигации
- **React Query** для управления состоянием
- **Telegram Web App API** для интеграции
- **Lucide React** для иконок

### Backend
- **Node.js** с Express.js
- **PostgreSQL** (основная БД)
- **SQLite** (локальная разработка)
- **JWT** для аутентификации
- **Telegram Bot API** интеграция
- **Axios** для HTTP запросов
- **Helmet** для безопасности

### Инфраструктура
- **Vercel/Netlify** для frontend
- **Railway/Render** для backend
- **Neon/Supabase** для БД

## 📊 API Endpoints

### Аутентификация
- `POST /api/auth/telegram` - Авторизация через Telegram
- `GET /api/auth/profile` - Получение профиля
- `PUT /api/auth/profile` - Обновление профиля

### Товары
- `GET /api/products` - Список товаров с фильтрацией
- `GET /api/products/:id` - Детали товара
- `GET /api/products/categories` - Список категорий
- `GET /api/products/featured/popular` - Популярные товары
- `GET /api/products/featured/discounts` - Товары со скидками

### Заказы
- `POST /api/orders` - Создание заказа
- `GET /api/orders/my` - История заказов
- `GET /api/orders/:id` - Детали заказа
- `PUT /api/orders/:id/cancel` - Отмена заказа

### Платежи
- `POST /api/payments/create` - Создание платежа
- `GET /api/payments/status/:id` - Статус платежа
- `GET /api/payments/history` - История платежей

### Telegram
- `POST /api/telegram/webhook` - Webhook для обновлений
- `GET /api/telegram/bot-info` - Информация о боте
- `POST /api/telegram/send-message` - Отправка сообщений
